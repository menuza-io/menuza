# Authentication

Epic Stack comes with a robust authentication system out of the box. It supports various authentication methods:

## Email/Password Authentication

The classic approach to authentication:

- Secure password hashing with bcrypt
- Email verification flow
- Password reset functionality
- Optional two-factor authentication

## OAuth Authentication

Social login options:

- GitHub OAuth integration
- Google OAuth integration
- Easy to add other OAuth providers

See the [GitHub and Google Login Setup guide](/essentials/oauth-login) for
provider-console setup, callback URLs, environment variables, local development,
Cloudflare secrets, and troubleshooting.

## Passkeys

Modern authentication with passkeys (WebAuthn):

- Biometric authentication support
- No more passwords
- Enhanced security

## Single Sign-On (SSO)

Enterprise OpenID Connect (OIDC) authentication:

- Okta, Microsoft Entra ID (Azure AD), Google Workspace, Auth0, and custom OIDC providers
- OIDC Discovery (`/.well-known/openid-configuration`) with connection testing
- PKCE (RFC 7636) and AES-256-GCM encrypted tokens
- Just-in-Time (JIT) user auto-provisioning and role assignment
- Domain restrictions and email verification enforcement

Read the [Single Sign-On (SSO) Guide](/essentials/sso) for complete setup instructions.

## Sessions

Session management is handled securely:

- HTTP-only cookies
- CSRF protection
- Configurable session duration
- Active session listing and management
